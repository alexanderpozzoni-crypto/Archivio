ARCHIVIO 6.0 DIRETTO

- Non usa più Documenti_Unificati.
- Non copia i documenti.
- Scansiona direttamente la memoria del telefono.
- Indicizza PDF, foto, ZIP, RTF, DOCX, XLSX, TXT, CSV, LOG, EML.
- OCR foto e PDF scansione.
- Evita i doppioni usando SHA-256.
- Aggiornamento incrementale: file invariati saltati.
- "Chiedi all'AI locale" cerca nel contenuto e restituisce i risultati più pertinenti con estratti.
- Per Android 11+ serve una sola volta ACCESSO -> Consenti accesso a tutti i file.

EMAIL:
La scansione locale trova anche file .EML presenti sul telefono.
Per leggere direttamente Gmail nuove mail/allegati senza salvarli sul telefono serve OAuth Google/Gmail API
e quindi un Client ID Google configurato per l'app. Questa parte non può essere resa realmente automatica
senza le credenziali OAuth del progetto Google.
