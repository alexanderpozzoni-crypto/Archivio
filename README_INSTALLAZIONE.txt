ARCHIVIO 5.0 FULL AI - CODEASSIST

OBIETTIVO
Versione Android nativa: niente Termux e niente MacroDroid.

FUNZIONI INCLUSE
- Selezione Documenti_Unificati con selettore Android.
- Permesso persistente alla cartella.
- Scansione ricorsiva sottocartelle.
- Indicizzazione incrementale: i file invariati NON vengono rielaborati.
- Database SQLite locale.
- Hash SHA-256 per rilevare duplicati.
- Conteggio duplicati.
- Estrazione testo dai PDF.
- OCR automatico dei PDF scansione.
- OCR immagini JPG/JPEG/PNG/WEBP.
- Lettura TXT/CSV.
- Estrazione base DOCX.
- Estrazione base XLSX.
- Ricerca nel NOME e NEL CONTENUTO.
- Ricerca AI LOCALE: espansione sinonimi/termini collegati e ranking per pertinenza.
- Nessun documento inviato a servizi cloud.
- Apertura del file originale.
- Pulsante STOP: l'indice già creato rimane salvato.
- L'indice sopravvive alla chiusura e riapertura dell'app.

INSTALLAZIONE CON CODEASSIST
1) Scaricare Archivio_CodeAssist_FULL.zip.
2) Estrarre lo ZIP sul telefono.
3) Aprire CodeAssist.
4) Open Project / Apri progetto.
5) Selezionare la cartella Archivio_CodeAssist_FULL.
6) Lasciare risolvere le dipendenze.
7) Build / Run / Assemble APK.
8) Installare l'APK.
9) Aprire Archivio.
10) Premere CARTELLA.
11) Selezionare Documenti_Unificati.
12) Confermare "Usa questa cartella".
13) Parte l'indicizzazione.

IMPORTANTE SULLA PRIMA INDICIZZAZIONE
La prima scansione può richiedere parecchio lavoro se ci sono molti PDF scansione,
perché ogni pagina deve essere convertita in immagine e letta con OCR.
Dalla seconda volta, grazie all'indicizzazione incrementale, i file invariati vengono saltati.

AI LOCALE
Questa build non richiede Gemini, OpenAI o chiavi API.
La modalità "Ricerca AI locale" usa il testo estratto/OCR, normalizzazione,
sinonimi e un ranking di pertinenza. È privata e funziona offline.
